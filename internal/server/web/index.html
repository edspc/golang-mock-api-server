What goes in here
  • validation runs first. Failing requests are still captured, with every reason attached, and get onFailure (or 400 listing the reasons).
  • rules are tried in order, first match wins. A rule with no path matches any sub-path below the endpoint URL.
  • response answers requests that validated but matched no rule.
  • Response bodies are templates: {{.Body.event}}, {{.Body.data.id}}, {{.Path.id}}, {{.Query.source}}, {{.Header.XApiKey}}, {{now}}.
  • Saving replaces the spec wholesale. If it is rejected, the previous spec keeps serving.
